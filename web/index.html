WHAT HAPPENS, IN ORDER

The workflow, the model, and the feedback are different things.

  1. Make the ad. A graph is a recipe of connected steps. For Aurora: describe a backpack scene, generate the picture, add the brand and copy.
  2. Convert the recipe to code. Import an accepted ComfyUI API graph below. Angelos checks its connections and writes a readable program. No image is generated and no model is trained by conversion.
  3. Make examples and rate them. Run the full recipe in ComfyUI for different customer personas. Export finished ads with the permitted profile inputs used to make them. Grade quality and brand fit.
  4. Train a smaller model. This model—the “student”—learns from the examples, so the eventual ad can be generated without replaying every step. A UPL holds permitted audience facts and their numeric representation. It supplies inputs, not a pre-made ad.
  5. Train and compare new versions. A “critic” learns from human ratings. Candidate training uses click feedback together with that critic, aiming for more clicks without losing quality or brand fit. Keep the old model unless the new one passes evaluation.

Try here: convert a supported graph, inspect the built-in recipe, edit fictional preferences, view the available student, and save local ratings or test clicks. Training runs separately through local commands. Saving a rating does not update the model.

Still unproven: a sharp campaign-trained HD student, useful personalization and improved click rates. The saved HD image is a separate pretrained example. No real people are tracked and no ads are bought.

    STEP 05 / DISTILLATION & CANDIDATE LEARNING
    Make it smaller.
    Then earn “better.”
    Distillation trains a smaller student to imitate the full recipe. That is separate from learning what people prefer. Experimental reinforcement learning (RL) uses feedback-based rewards to train a proposed next model—a candidate.

    THE IDEA, IN PLAIN ENGLISH
    A recipe. A smaller model. A learning loop.
    A research foundation, not a finished advertising platform.
    Why split the work?
    Like a ComfyUI-style workflow, a full creative recipe connects operations. It can be expensive to run. This experiment trains a smaller model to approximate it, then runs the smaller model in the browser. Feedback can help evaluate what to try next, but improvement must be measured—not assumed.
    Graph / node
    A connected recipe / one step in it.
    Teacher
    The full offline workflow that supplies training examples.
    Student / distillation
    A smaller model / training it to imitate the teacher.
    UPL / encoder
    Preference numbers / the rule that creates those numbers.
    Artifact / weights
    The saved numbers a trained model uses. They must match the recipe.
    WebGPU
    The browser feature used to run the student on a graphics adapter.
    RL candidate / promotion
    A proposed model trained using reward signals / an explicit decision to replace the current one after evaluation.
    What this page does not establish
    Native 1080 campaign-student generation, useful personalization, higher conversion rates, automatic reinforcement learning, or production readiness. Raw student pixels and any separately composited brand mark remain visibly distinct.
