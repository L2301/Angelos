01 / What this actually doesStart with the ad, not the jargon

Your workflow makes the examples.
A smaller model learns from them.

  1. Make one ad in ComfyUI.

    A graph is just connected steps: write a prompt, generate a scene, add a logo and text. First, get an ad you would actually use.

  2. Turn an accepted graph into code.

    Angelos converts a supported ComfyUI API export into a readable, type-checked program. It keeps the connections and settings. Unsupported nodes are rejected, not guessed at.

  3. Make and grade examples.

    Run the full workflow for different customer personas. Rate the finished ads for quality and brand fit. A UPL is the person’s permitted facts plus a numeric representation—not the ad itself.

  4. Train a smaller image model.

    Use those examples to teach a campaign-specific diffusion model. The goal is to generate new ads faster, without running the whole workflow each time. This training step is separate from converting the graph to code.

  5. Test new versions using clicks and ratings.

    A critic learns from the ratings. Click feedback and the critic guide training of candidate models: aim for more clicks while keeping quality and brand fit. Evaluate a candidate before replacing the current model.

For example: Aurora backpacks.

You make a backpack ad beside a lake. The intended system could make a calmer or more energetic version for different permitted preferences, then test which model works better. That useful personalization has not yet been demonstrated.

What works now: a limited ComfyUI graph-to-program converter, image-pack import, local preference encoding, a small browser diffusion experiment, and separate feedback-training tools.

What does not work yet: a good-looking campaign-trained HD student, proven personalization, or measured click-rate improvement. The HD ad below uses a pretrained model and separately authored text. This is not an automatic ad-buying service.

System schematicNot a live inference

Model updates are implemented as manual, local click + critic training runs. They create candidates for evaluation—not automatic replacements. The tested student remains 32 × 32.

UPL v2 / ingredients before inference

A person is not a targeting label.

Declared interests, goals, visual styles and language stay separate from recent view, click, save and dismiss events. Facts, event history, permission and encoder revisions change independently. An opaque identity reference is not the representation itself.

The local lab offers explicit cached Qwen3-Embedding inference, starting at 512 dimensions. Missing weights fail clearly: no automatic downloads or fake fallback. Embeddings are not anonymous. Synthetic adults only; personal-data collection and tracking are not enabled.

Trainable adapter infrastructure is not a trained conditioning model. A semantic vector cannot simply be plugged into a generator’s conditioning port. The 4D WebGPU path remains a legacy fixture; compatible adapters and useful personalization need independent evaluation.

Recorded real CPU embedding execution ↗ verifies the encoder ran—not a learned campaign adapter or CTR lift. A first cold local encode may take about 20 seconds, including worker/model loading; not a GPU latency claim.

Architecture / explicit operation boundaries

Creative direction, with a structure.

A human-readable, typed graph connects creative intent, deterministic operations, and reviewed open-model adapters. A prompt node selects or formats text; the learned generate_text node is a separate model operation, with its own execution evidence.

Model execution is not implied by a graph label. Tiny-SD has documented real-weight evidence; FLUX and LTX adapter tests alone do not establish live execution. Unsupported operations must fail explicitly.

Training / bounded diffusion proof

The recipe is not the learned model.

Build the ad in ComfyUI, or use the smaller typed graph here. Complete rendered examples are the teaching material for a separate campaign model. Exporting a workflow does not train a student, and the student does not simply replay the graph.

Reward fitting and candidate optimization are implemented experiments. A critic validated on substantial human ratings and a useful campaign-trained HD student remain unproven.

Runtime / measured at 32 × 32

Small enough for a different runtime.

The current compact campaign diffusion student runs its denoising loop in browser WebGPU. It is a real trained model, but only a 32 × 32 proof. Enlarging the preview does not create high-resolution detail.

The raw learned brand failed its fidelity gate. An explicit exact-brand compositor supplies the tested mark instead; it does not fix the rest of the image. Useful personalization has not been demonstrated.

Implemented / candidate model training

Learn from what actually happened.

A click belongs to an exposed creative, its seed, its model, and the profile snapshot at exposure time—not the latest profile. Eligible feedback needs consent and a completed attribution window. A preview is not an impression.

The local trainer updates diffusion weights using predicted clicks plus separate quality and brand constraints, then saves and evaluates candidate models. Run it explicitly with npm run rl; saving feedback does not start training. The recorded native-32 smoke run changed weights, but both candidates failed their gates. No automatic nightly jobs, production promotion, real ad traffic or measured performance lift is claimed.

Teacher execution

Measured

Real Tiny-SD weights and full-graph examples on Apple MPS. Registered FLUX and LTX adapters are not evidence that their full weights have run.

Text, not templates

Measured

A separate Qwen3-0.6B node writes text that feeds Tiny-SD. Real CPU execution was checked end to end. Prompt formatting remains deterministic; browser text inference is not claimed. Inspect the text contract ↗

Browser diffusion

Measured

The trained 32px student executes in hardware WebGPU, with numerical parity checks against PyTorch. This verifies execution, not ad quality.

Useful personalization

Not demonstrated

The reported UPL-conditioning audit failed: mismatched inputs performed slightly better on noise MSE. Pixel variation is not meaningful personalization.

Brand fidelity

Explicit fallback

The raw neural mark failed its gate. The tested exact compositor restores that mark; arbitrary logos, required copy, and overall brand quality are not thereby solved.

Human judgment

Needs evidence

Separate quality and brand reward heads can be trained and evaluated on held-out profiles. Synthetic-label tests are not validation of a human preference critic.
