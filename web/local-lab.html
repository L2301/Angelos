Local research laboratory / not a hosted service

Bring the experiment
to your machine.

This is the static Angelos showcase. It includes the idea, research and recorded evidence. It deliberately does not expose a profile database, model runner or unauthenticated laboratory API.

The idea in plain English: make an ad workflow in ComfyUI, generate examples and rate them, then train a smaller model to make similar ads faster. Use ratings and click feedback to train and compare new versions. These are separate steps, not one automatic process. A useful campaign-trained HD model and better click rates are still unproven.

Explore first. Download models only when you choose.

The local interface and graph editor run without Python, model weights or WebGPU. Actual text generation needs a cached model; the learned image preview needs a trained artifact and hardware WebGPU.

01 / Explore locally

With repository access and Node 24 or newer, run these commands from your checkout:

npm ci
npm start

Then open http://127.0.0.1:4310/lab. A fresh checkout honestly shows that no trained student is loaded.

02 / Make the ad in ComfyUI

The local lab can turn a supported API-format ComfyUI graph into a readable, type-checked program and back into API JSON. Unsupported nodes fail explicitly. This runs locally without models; it does not generate an ad or train weights.

Use the canvas you already know. Keep your model and sampler nodes, finish the ad with its branding, then attach the Angelos export nodes. They save the creative and its workflow provenance for the next stages; exporting is not training.

Install the ComfyUI bridge and follow the workflow. The built-in Angelos graph is a smaller inspectable alternative.

03 / Run a real text node

Install Python 3.11 and the model dependencies, then explicitly cache the lightweight Qwen3 checkpoint. Review its model license first.

python3.11 -m venv .venv
.venv/bin/python -m pip install -r ml/requirements-generative.txt
npm run models -- download qwen3-0.6b

Use the lab’s text probe to generate actual model output. prompt() formats instructions; generate_text() runs the language model. Neither training nor model downloading happens just because you open the page.

04 / Inspect UPL ingredients before encoding

After building the ad in ComfyUI, use the local lab to declare fictional interests, goals, visual styles and language, and explicitly record synthetic intent events. Facts, events and permissions have separate revisions. Encode only when you choose, using a cached Qwen3-Embedding model at 128, 256, 512 (default) or 1024 dimensions. Missing weights fail without automatic downloads or fake vectors.

The first cold local encode may take about 20 seconds, including worker/model loading. Timing varies by machine; this is not a GPU latency claim.

Recorded real CPU embedding execution verifies that the encoder ran, not that a campaign adapter was learned or click rates improved.

Copy v2 only after a successful current encode. The separate 4D WebGPU handoff is a legacy fixture. Trainable adapter infrastructure is not a trained conditioning model, and embeddings are not anonymous. No real browsing histories, paid jobs, automatic training or promotion are enabled.

05 / Inspect the boundaries

The browser student remains a 32×32 engineering experiment whose conditioning audit failed. A separate local foundation-model run produced genuine 1920×1080 imagery, not an enlarged student preview. The critic and click-driven candidate experiments do not establish measured click-rate lift or a finished campaign-trained HD model.
